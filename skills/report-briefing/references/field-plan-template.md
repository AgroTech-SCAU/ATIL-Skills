# 事前安排占位模板

从下方文档标题起取正文，保留 Markdown 标题、分级编号与 `---` 分隔线，不另包代码块；标题后和一级章节之间各放一条分隔线，前后留空行

【任务 1 名称】等表示待替换的任务标识；在第5至第8节保持相同名称、任务编号末段和顺序，例如 `5.1.`、`6.1.`、`7.1.`、`8.1.` 均对应任务1；按实际任务数增删，不固定为两项

无关字段或可选章节可省略；一级章节调整后连贯编号，任务对应关系保持不变；末尾不追加总结

车辆条目按实际数量扩展，未提供的数量、上车地点与电话保留占位；其他现场对接人放在车辆之后，已列为车辆联系人时引用对应车辆，不重复抄写联系方式；当次另有打车安排人时按用户材料替换
