# 事后汇报占位模板

从下方文档标题起取正文，保留 Markdown 标题、分级编号与 `---` 分隔线，不另包代码块；标题后和一级章节之间各放一条分隔线，前后留空行

默认采用总体结果、各项任务完成情况、问题分析、后续安排四节；协调请求有则另加第5节，末尾不追加总结

第2至第4节沿用事前任务名称、编号末段和顺序，例如 `2.1.`、`3.1.`、`4.1.` 均对应任务1；按实际任务数扩展，问题与后续安排只列相关任务，省略条目时保留其余任务编号；临时新增任务另列并注明

实际执行情况仅补充必要背景和变化，联系人变动或对接问题集中写在 `1.3.`；成果名称、存放位置、整理人与检查状态放入各任务“实际结果”，不重复列出
